# Inspira Capital - Site Institucional

Site institucional desenvolvido para a **Inspira Capital**, empresa onde atuou-se estrategicamente ao longo de 4 anos de experiência e desenvolvimento contínuo. O projeto apresenta a identidade da empresa, seus serviços e canais de contato, estruturado sob uma arquitetura limpa e organizada.

---

## 🚀 Tecnologias Utilizadas

O projeto foi construído utilizando tecnologias web fundamentais e estruturado em um padrão robusto de desenvolvimento:

* **Linguagem:** PHP (Paradigma Orientado a Objetos / Arquitetura MVC)
* **Frontend:** HTML5, CSS3, JavaScript
* **Servidor Web:** Apache

---

## 🏛️ Arquitetura (MVC)

O projeto segue o padrão **Model-View-Controller (MVC)** para garantir a separação de responsabilidades, facilitar a manutenção e escalabilidade do código:

* **Model (Modelo):** Responsável pela lógica de negócios e manipulação de dados.
* **View (Visão):** A interface com o usuário (páginas HTML/CSS/JS renderizadas).
* **Controller (Controlador):** O intermediário que recebe as requisições do usuário, aciona os Models necessários e retorna as Views correspondentes.

---

## ⚙️ Pré-requisitos

Para rodar este projeto localmente, certifique-se de ter instalado em sua máquina:

* Um servidor local que suporte PHP e Apache (como **XAMPP**, **WampServer** ou **MAMP**).
* PHP (versão 7.4 ou superior recomendada).

---

## 🔧 Como Executar o Projeto

1. **Clone o repositório** (ou baixe os arquivos do projeto).
2. **Mova a pasta do projeto** para o diretório raiz do seu servidor Apache:
   * No *XAMPP*, por exemplo: `C:/xampp/htdocs/inspiracapital-site/`
3. **Inicie o Apache:**
   * Abra o painel de controle do seu servidor local (XAMPP/Wamp) e certifique-se de que o **Apache** está rodando (`Start`).
4. **Acesse no navegador:**
   * Abra o seu navegador de preferência e acesse o endereço:
     ```text
     http://localhost/inspiracapital-site/
     ```
